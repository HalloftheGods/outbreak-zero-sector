# Outbreak: Zero Sector

A Hall of the Gods, Inc. game. A top-down pixel art zombie survival game set in an open town at night. Ammo and health are finite, so you search the town's buildings for them, and every gunshot tells nearby zombies where you are.

**Play solo in your browser:** https://hallofthegods.github.io/outbreak-zero-sector/

Co-op needs the game server, which GitHub Pages cannot host. Run it yourself to play together; see [docs/README.md](docs/README.md).
